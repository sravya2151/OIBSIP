# Retail Sales Exploratory Data Analysis (EDA)

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a Retail Sales Dataset using Python. The objective is to analyze sales performance, customer demographics, product categories, and identify business insights through data visualization.

---

## Objective

- Perform data inspection
- Check missing values
- Generate descriptive statistics
- Analyze monthly and quarterly sales
- Analyze customer demographics
- Identify top-selling products
- Analyze revenue by product category
- Generate a correlation heatmap
- Provide actionable business recommendations

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Dataset

Retail Sales Dataset from Kaggle
